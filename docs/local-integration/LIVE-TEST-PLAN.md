# Local runtime live-test boundary

A live test is optional and requires explicit operator authorization.

1. Confirm the ignored local runtime profile is present and trusted without
   copying its contents into the repository.
2. Verify the configured listener remains loopback-only.
3. Run one bounded, non-sensitive request at the configured picker effort.
4. Verify only public outcomes: selected model identity, terminal completion,
   and a durable scoped edit when the task asks for one.
5. Keep raw prompts, request identifiers, logs, screenshots, model artifacts,
   hardware details, and performance figures outside tracked documentation.

Do not turn this into a machine inventory or benchmark protocol.
