# Public session handoff

This handoff is deliberately limited to public behavior:

- The managed Qwen default is 192K with an explicit 128K row.
- Qwen defaults to xhigh reasoning and exposes low, medium, and xhigh only.
- The machine-local runtime profile is ignored and is never reproduced in
  tracked handoff notes.
- A live local run requires explicit operator authorization.

Do not add local paths, hardware placement, artifact metadata, logs, screenshots,
benchmark data, account identifiers, or recovery instructions to this file.
